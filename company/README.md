# jarvis-company

Phase B skeleton of the Jarvis Software Corporation orchestration layer.
This package is a scaffold only — no orchestration logic is implemented yet.

## Planned directories

- `src/` — orchestration source code
- `config/` — configuration files
- `prompts/` — prompt templates
- `tests/` — tests (Node built-in test runner)
- `state/` — runtime-only state; git-ignored, never committed

## Testing

Run from the `company/` directory:

```
node --test
```

## Dependencies

Zero runtime dependencies. Only Node.js built-ins are used.
